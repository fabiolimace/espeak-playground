Manual normalization
==================================

This document lists tips for manual normalization on the fly, i.e. while typing texts.

The goal of this document is to raise awareness of visual writers about how to write more accessible texts for users of text-to-speech software.

The following instructions contain examples in Portuguese.

* Type cardinal numbers up to 10 as words, e.g.: "um, dois, três" instead of "1, 2, 3".
* Type ordinal numbers with an ordinal indicator and without a point between them, e.g.: "1ª" instead of "1.ª".
* Type big numbers with a dot as thousands separator, e.g.: "1.000" instead of "1 000".
* Type cardinal numbers refering to feminine nouns as words. e.g.: "duas colheres" instead of "2 colheres".
* Type ordinal numbers refering to feminine nouns as words. e.g.: "a Primeira Dama" instead of "a 1ª Dama".
* Type dates as words, e.g.: "primeiro de janeiro de 1970" instead of "01/01/1970".
* Type time of the day as words, e.g.: "dez horas" ou "dez e trinta da noite" instead of "10h" or "10:30 PM".
* Type Roman numbers as words, e.g.: "Dom Pedro Primeiro", instead of "Dom Pedro I".
* Type people titles as words, not abbreviations, e.g.: "Doutor João" instead of "Dr. João".
* Type consonant prefixes in upper case, e.g.: "GZip" instead of "gzip"; "JPeg" instead of "jpeg".
* Type compound names in separate words when possible, e.g.: "check in" or "check-in" instead of "checkin".
* Type sentences in lower case and starting with upper case, e.g.: "Eu te amo!" instead of "EU TE AMO!".
* Do not type abbreviations in the end of sentences, e.g.: never type "Sim, dr. Eu entendi."; instead, type "Sim, doutor. Eu entendi.".
* Do not type acronyms in lower case, e.g.: don't type "fbi", but "FBI".
* Do not type month abbreviations, e.g.: 25 dez. 1999; instead, type "25 de dezembro de 1999".
* Do not type acronyms with an "s" to indicate plural, e.g.: don't type "os CEOs", but "os CEO".
* Do not use markup symbols with text if you are writing on a plain text field or document.
* Do not use all upper case letters, unless you are typing an acronym. If you want to shout out, use exclamation point, not upper case.
* Do not use a foreign word when there's an equivalent word in native language, e.g.: type "prazo" instead of "deadline".
* Do not alternate languages in a single document. If break this rule, indicate that the next piece of text is in another language, e.g.: the next paragraph is in English or the following phrase is in French.
