Automatic Normalization
==================================

Numbers
----------------------------------

### Thousands

* 1.000 -> 1000
* 1 000 -> 1000
* 1.000,00 -> 1000,00
* 1 000,00 -> 1000,00

### Intervals

* 1-10 -> 1--10
* 2025-2026 -> 2025--2026

### Ordinals

* 1.ª -> 1ª
* 1.º -> 1º

#### Ordinals as superscripts

* 1^a^ -> 1ª
* 1^o^ -> 1º

#### Ordinals as lowercases

* 1a -> 1ª
* 1o -> 1º

#### Ordinals as degrees

* 1° -> 1º

#### Ordinals as ring above

* 1U+02DA -> 1º
