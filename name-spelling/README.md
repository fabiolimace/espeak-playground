Brazilian Name Spelling
======================================

Unlike in Portugal, in Brazil creatively altering the spelling of people's names is a very common practice. This script helps fine-tune eSpeak NG to reflect this important Brazilian cultural characteristic.

Example:

	$ ./name-spelling-comparison.sh fábio
	fábio	fabio	fˈabjʊ	fˈabjʊ	EQ
	fábio	fábio	fˈabjʊ	fˈabjʊ	EQ
	fábio	fabyo	fˈabjʊ	fˈabjʊ	EQ
	fábio	fábyo	fˈabjʊ	fˈabjʊ	EQ

Where:

* EQ: equals
* NE: not equals
* OK: not equals but it's ok
